# LoveWebAdmin

Веб-панель администрирования для Love* серверов с поддержкой управления игроками, мониторингом серверных метрик и интеграцией LuckPerms.

## Общая структура

LoveWebAdmin предоставляет веб-интерфейс (обычно на `localhost:8080` или настраиваемом хосте/порту) для удаленного администрирования серверов Love* экосистемы. Панель позволяет просматривать онлайн-игроков, управлять правами доступа (через LuckPerms), просматривать логи, отправлять команды, мониторить состояние сервера и экономики в реальном времени.

## Команды

| Команда | Алиасы | Описание | Пермишин |
|---|---|---|---|
| `/lwa` | — | Управление веб-панелью (info, reload, resetowner) | `lovewebadmin.admin` |

### Подкоманды `/lwa`

- `info` — показать информацию о веб-панели (URL, статус, токен)
- `reload` — перезагрузить конфигурацию панели
- `resetowner <password>` — создать новый токен доступа (пароль администратора)

## Пермишины

| Пермишин | Описание | Default |
|---|---|---|
| `lovewebadmin.admin` | Доступ к команде `/lwa` и всем админ-функциям на сервере | op |

## Конфигурация (`config.yml`)

### Основные параметры

```yaml
plugin:
  enabled: true
  debug: false

# Веб-сервер
web:
  enabled: true
  host: "0.0.0.0"                  # на каком интерфейсе слушать (0.0.0.0 = все)
  port: 8080                       # порт веб-панели
  use-ssl: false                   # использовать HTTPS (требует certificates/)
  ssl-port: 8443                   # порт HTTPS

# Аутентификация
auth:
  token-auth-enabled: true         # требовать токен для доступа
  session-timeout-minutes: 30      # сессия действует 30 минут
  max-login-attempts: 5            # попыток входа перед блокировкой
  lockout-duration-minutes: 15     # блокировка на 15 минут

# Логирование действий
logging:
  enabled: true
  log-player-actions: true         # логировать действия в админ-панели
  log-file: "webadmin.log"
  keep-history-days: 30

# Мониторинг
monitoring:
  enabled: true
  refresh-interval-seconds: 5      # обновляет метрики каждые 5 сек
  track-tps: true                  # отслеживать TPS сервера
  track-memory: true               # отслеживать использование памяти
  track-players: true              # отслеживать онлайн-игроков
  track-economy: true              # отслеживать состояние экономики (LoveCore)

# Интеграция с LuckPerms
luckperms:
  enabled: true
  sync-interval-minutes: 5         # синхронизировать с LuckPerms каждые 5 минут

# Веб-сокет (для реального времени)
websocket:
  enabled: true
  max-connections: 100
```

## Функции веб-панели

### Управление игроками

- **Список онлайн** — показать всех игроков на сервере с их характеристиками
- **Инфо игрока** — просмотреть детальную информацию (UUID, IP, время входа, инвентарь)
- **Управление правами** — добавить/удалить группы и пермишины через LuckPerms
- **Телепортация** — телепортировать игрока в определённую точку (требует пермишин)
- **Отправка сообщений** — отправить приватное сообщение игроку
- **Кик/Бан** — выкинуть или забанить игрока с причиной

### Мониторинг сервера

- **TPS** — показать текущий TPS сервера (желателен >19 TPS)
- **Память** — использование оперативной памяти Java-процессом
- **Логи ошибок** — просмотр последних ошибок и предупреждений
- **Статистика игровых систем** — интеграция с Love* плагинами:
  - Активные охоты (LoveHunt)
  - Активные контракты (LoveContracts)
  - Войны кланов (LoveClans)
  - Экономика серверов (LoveCore)

### Команды сервера

- **Консоль** — выполнять команды напрямую (требует пермишина)
- **Отправка сообщений** — отправить сообщение всему серверу

### Экспорт и отчёты

- **Экспорт статистики** — скачать CSV с данными игроков
- **Резервная копия** — создать резервную копию БД
- **Отчёт по деятельности** — детальный отчёт за период

## Интеграции

### LuckPerms

Полная интеграция с LuckPerms для управления правами доступа игроков и групп. Панель может читать и писать данные LuckPerms.

### LoveCore

Интеграция с LoveCore для просмотра:
- Баланса игроков (LoveEconomy)
- Активных профилей
- Репутации (ReputationOracle)

### LoveHunt

Показывает активные охоты, статистику охотников.

### LoveContracts

Показывает активные контракты, статистику выполнения.

### LoveClans

Показывает информацию о кланах, войнах, территориях (требует LoveClaims).

## Безопасность

- **Токен-аутентификация** — требует уникального токена для доступа к панели
- **Кулдауны и блокировки** — защита от brute-force атак
- **Логирование действий** — все админ-действия фиксируются в логе
- **HTTPS поддержка** — опциональное шифрование передачи данных
- **Сессии** — таймауты сессий для безопасности

## Структура данных

- `web_sessions` — активные веб-сессии (токен, IP, дата создания, дата истечения)
- `admin_logs` — логи действий администраторов (дата, администратор, действие, детали)
- `server_metrics` — метрики сервера (время, TPS, память, игроки онлайн)

## Первоначальная настройка

1. **Запустить сервер** с LoveWebAdmin
2. **Посмотреть URL и токен** — `/lwa info`
3. **Открыть веб-панель** — http://localhost:8080 (или настроенный хост)
4. **Войти с токеном** — скопировать токен из `/lwa info`
5. **Изменить пароль администратора** — `/lwa resetowner <новый_пароль>`

## Доступ из интернета

Если нужно администрировать сервер удалённо:

1. Настроить firewall для доступа к порту 8080 (или 8443 для HTTPS)
2. Включить `use-ssl: true` в конфиге и поместить сертификаты в папку `certificates/`
3. Рекомендуется использовать обратный прокси (nginx, Cloudflare) для безопасности
