# Общая статистика сервера и рабочая сводка

В разделе «База данных» переключается весь экран. «Уникальные игроки» сохраняет прежние показатели, график, период и карточку поиска игрока. «Общая статистика сервера» открывается отдельно. Это не переключатель в досье отдельного игрока.

## Данные общей статистики

| Раздел | Что измеряется | Источник и охват |
|---|---|---|
| Аккаунты и активность | Аккаунты в базе, накопленное время, активность за сутки и неделю | Известные WebAdmin аккаунты |
| Наказания | История, действующие и снятые баны | SQLite WebAdmin; истёкший срок исключается из действующих |
| Жалобы | Всего, открытые, подтверждённые, отклонённые | SQLite WebAdmin |
| Апелляции | Всего, открытые, пересмотренные наказания | SQLite WebAdmin |
| Проверки и ограничения | Активные заморозки и муты | Служба модерации, с учётом прав |
| Безопасность аккаунтов | Зарегистрированные и заблокированные аккаунты, сохранённые сессии | Асинхронная сводка LoveAuth; без паролей, токенов и IP |
| Кланы | Количество кланов, участников и территорий | Публичное API LoveClans |
| Дуэли | Активные дуэли | Публичный менеджер LoveDuels |
| Охота | Активные заказы, охотники с рейтингом | Зарегистрированный API LoveHunt |
| Контракты | Доступные контракты и онлайн-игроки с контрактом | Кэш LoveContracts |
| Адаптации | Распределение адаптаций среди игроков онлайн | Кэш LoveAdaptation; отдельно указан охват |
| Поведение | Средняя вежливость и стиль игроков онлайн | API LoveBehavior; отдельно указан охват |
| Торговля | Число сервисных NPC торговли | Публичное API LoveShops; это не число сделок или глобальная выручка |
| Экономика | Монеты отслеживаемых онлайн-игроков, охват и время измерения | Существующий снимок LoveCore/LoveEconomy; не весь денежный оборот сервера |
| Античит | Записи очереди, применённые и требующие проверки | Сводка волны Vesuvio |

Отсутствующая/несовместимая интеграция не подменяется нулём. У карточки есть источник, время чтения и признак сохранённого снимка. Период посещений из первого режима не применяется к счётчикам за всю историю или текущему состоянию.

SQLite дополнена таблицей `server_metric_snapshots`: последний снимок каждого известного раздела, источник и время. Запись обновляется на месте; новый раздел на каждый запрос не создаётся. Более старый результат не перезаписывает новый. Размер одного снимка ограничен. Это не перенос чужих баз и не полная историческая телеметрия всех плагинов.

Сбор через Bukkit и кэш плагинов выполняется на основном потоке. SQL и ожидание асинхронного ответа LoveAuth остаются на HTTP-потоке. Ответ общей статистики кэшируется на 5 секунд, максимум для 16 наборов прав. Текущие права перепроверяются перед обращением к кэшу одним чтением аккаунта/роли; закрытые разделы не выдаются из ранее сохранённых снимков.

## Рабочая сводка

Сводка находится в дашборде, перед плитками. Режимы: «Мои и свободные» и «Вся очередь». Пустые карточки скрываются. В зависимости от прав и данных доступны:

- предварительные баны с отсчётом до истечения оформления;
- обращения без ответственного;
- дела, ожидающие ответа сотрудника;
- превышенные сроки ожидания;
- ожидание ответа игрока;
- обращения поддержки;
- доставки с ошибкой/неизвестным результатом;
- очередь волны наказаний.

Открывается соответствующая очередь с пагинацией по 20 элементов, а затем конкретное дело. Закрытие дела возвращает в очередь. Оформление предварительного бана тоже открывается вложенным окном. Доставка ведёт в существующий экран сверки, банволна — в её вкладку. Сводка ничего не применяет и не повторяет автоматически.

Ожидание и сроки дел используют сохранённое состояние workflow; оно актуализируется существующей обработкой обращений. Это не мгновенная телеметрия Discord. Сводка перечитывается раз в 15 секунд, таймер оформления — раз в секунду. При уходе с дашборда интервалы удаляются. Счётчики и короткие страницы читаются SQL-запросами без выгрузки текстов дел и payload уведомлений.

## Проверки и установка

Конфиги менять не требуется. Новая таблица добавляется без удаления прежних данных. Заменять JAR нужно после остановки сервера; сохраняйте SQLite и каталог libraries.

Есть регрессии прав, офлайн-снимков интеграций, старых ответов, пагинации, возврата из дела, остановки обновлений, изоляции Preview и мобильного интерфейса. Проверки настоящего Paper/Purpur и всех живых Love-плагинов этой сборкой не выполнялись: совместимость методов сверена с доступными исходниками, а поведение интерфейса — в изолированном Preview.
